# マンダラ・ノート 教師用マニュアル

児童用のマンダラ思考＆作文支援 Web アプリ「**マンダラ・ノート**」を、先生が自分の Google アカウントで導入・運用するためのマニュアル集です。

- 📘 **[教師用 導入マニュアル](教師用導入マニュアル.md)** — はじめて Google Apps Script（GAS）を使う先生でも、コードを貼って**デプロイ（公開）するまで**を、つまずきポイントつきで案内します。
- 📗 **[教師用 運用マニュアル](教師用運用マニュアル.md)** — **授業での使い方**・設定（手引き設定／プラン保管）・データ確認・困ったときをまとめています。

> 🍀 **マンダラ・ノートとは**
> 子どもがタブレットで「まん中のテーマ → まわりに広げる → さらに深める → 並べ替えて作文の下書きにする」を体験できる、発想＆作文支援ツールです。記録は先生の Google スプレッドシートに届きます。**完全無料・Google Apps Script 製**。
