マンダラ・ノート 教師用 導入マニュアル

このアプリを、自分の Google アカウントで動かして授業に使えるようにするまでの手順です。 Google Apps Script（GAS）を初めて使う先生でも、このとおりに進めればデプロイ（公開）まで到達できます。所要 約30分。

運用（授業での使い方）は 教師用 運用マニュアル をご覧ください。

必要なもの

  • Google アカウント（学校または個人）
  • Google スプレッドシート（無料）
  • 配布されたコード2つ：Code.gs と index.html
  • 児童が使うタブレット等のブラウザ

💡 用語ミニ知識（こわくありません） - GAS（Google Apps Script）＝ Google のサービスにくっつく簡単なプログラム。スプレッドシートから Web アプリを作れます。 - デプロイ＝ 作ったものを「Web アプリとして公開」して、URL を発行すること。 - やることは結局「コードを貼る → 公開する」だけです。

Step 1. スプレッドシートを用意

  1. Google ドライブで新しいスプレッドシートを作る。
  2. 名前を分かりやすく（例：マンダラノート_5年1組）。

このスプレッドシートが「先生用の管理画面＆データの保存先」になります。

Step 2. スクリプトエディタを開く

  1. スプレッドシートのメニュー 「拡張機能」→「Apps Script」 をクリック。
  2. 新しいタブでスクリプトエディタが開きます。

Step 3. コードを貼る（2ファイル）

(A) Code.gs（サーバー側） 1. 最初からある コード.gs（または Code.gs）を開く。 2. 中身をすべて選択して削除（Ctrl+A → Delete）。 3. 配布の Code.gs の中身を全部貼り付け。 4. 保存（Ctrl+S または 💾）。

(B) index（児童画面のHTML） 1. 左の「ファイル」欄の ＋ → 「HTML」 を選ぶ。 2. ファイル名を index にする（★ここ重要）。 - 必ず「index」。index.html と打っても拡張子は自動で付くので index だけでOK。名前が違うと画面が真っ白になります。 3. 出てきたHTMLの中身をすべて削除し、配布の index.html の中身を全部貼り付け。 4. 保存（Ctrl+S）。

✅ これでファイルは Code.gs と index（HTML）の2つになります。

Step 4. シートを初期セットアップ＋承認

  1. スプレッドシートのタブに戻り、ページを再読み込み（F5）。
  2. 数秒で上部メニューに 「🍀 マンダラ管理」 が増えます（出なければもう一度再読み込み）。
  3. 「🍀 マンダラ管理 → 🛠️ シートを初期セットアップする」 をクリック。
  4. 初回は承認画面が出ます（自分のスクリプトを自分のスプシで動かす許可）。次の順で進めます：
  5. 「権限を確認」→ 自分の Google アカウントを選ぶ
  6. 「このアプリは Google で確認されていません」と出たら → 「詳細」→「（プロジェクト名）に移動」
  7. 「許可」をクリック

    これは自分が用意したスクリプトを、自分のスプレッドシートで動かすための許可です。外部にデータは出ません。

  8. 完了すると 名簿・手引き設定・データ の3シートが自動でできます。

Step 5. 名簿を入れる

名簿 シートに、ログインさせたい児童を入力します（ここに載っている子だけログインできます）。

A列 B列 C列 D列 E列 F列
通し番号（参考） 学年 クラス 名簿番号 名前 パスワード
1 5 1 1 山田 太郎 hana123
2 5 1 2 鈴木 花子 sora456
  • ログインは B〜D・F列（学年・クラス・名簿番号・パスワード）を使います（A列の番号はログインに使いません）。
  • 学年・クラス・番号・パスワードは 半角で入力してください（児童画面でも全角だと文字が赤くなって気づけます）。
  • ⚠️ パスワードは本人にだけ伝える。印刷して個別に配るのが安全です。

Step 6. ウェブアプリとして公開（デプロイ）★最重要

ここが初めての方の山場です。ゆっくりどうぞ。

  1. スクリプトエディタの右上「デプロイ」→「新しいデプロイ」。
  2. 左上の歯車（種類の選択）→「ウェブアプリ」を選ぶ。
  3. 設定する：
  4. 説明：任意（例 マンダラノート v1）
  5. 次のユーザーとして実行：自分（あなたのアカウント）← 児童のデータがあなたのスプシに届くために必要
  6. アクセスできるユーザー：全員（児童が Google ログインなしで使える）
    • 学校のポリシーで「全員」が選べない場合は「◯◯（ドメイン）内の全員」を選ぶ
  7. 「デプロイ」をクリック → （初回は再度承認）→ ウェブアプリの URL が表示されます → コピー。
  8. その URL を児童に配る（ロイロノートのカード・Google Classroom・学校ポータル等）。
  9. 動作確認：URL を開いてログイン画面が出ればOK。名簿の1人でログインしてみましょう。

💡 URL は後からでも 「🍀 マンダラ管理 → 🌐 Webアプリを開く」 で確認できます。

導入でつまずいたら（FAQ）

  • 「🍀 マンダラ管理」が出ない → スプレッドシートを開き直す（初回は数秒かかります）。
  • 画面が真っ白／エラー → HTMLファイルの名前が index になっているか確認（最頻出ミス）。
  • 「このアプリは確認されていません」で進めない → 「詳細」→「（プロジェクト名）に移動」→「許可」。自作スクリプトなので問題ありません。
  • 児童がURLを開けない／ログイン要求される → デプロイの「アクセスできるユーザー」が「全員」になっているか確認。
  • データシートが見つからない → 児童が最初に「記録」を押すと自動でできます。まず1人試す。

コードを更新したとき（再デプロイ）

配布コードが新しくなったら：

  1. Code.gs と index を新しい中身に貼り替えて保存。
  2. スクリプトエディタ右上 「デプロイ → デプロイを管理」。
  3. 今のデプロイの 編集（鉛筆 ✏️）→ バージョン：「新しいバージョン」→ デプロイ。

⚠️ 保存しただけでは児童のURLには反映されません。 必ず「新しいバージョン」で再デプロイしてください。 （シートの設定変更＝授業ID・観点などは再デプロイ不要。児童の再ログインで反映されます。）
